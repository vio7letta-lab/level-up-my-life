# LEVEL UP: MY LIFE

RPG, где игровой мир — моя реальная жизнь.

**Real action → Game progress → Real life result.**
Прогресс в игре даёт только зафиксированный реальный результат, а не нажатие кнопки.

🔗 Игра: https://vio7letta-lab.github.io/level-up-my-life/

## Стек

React + TypeScript + Vite + Tailwind CSS v4. Без backend: данные хранятся в браузере
(через `StorageAdapter`, чтобы позже подключить аккаунт и облачную синхронизацию).

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm test           # тесты: движок, QA-чеклист, задачи, импорт и синхронизация (src/game/*.test.ts)
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть собранную версию
```

## Деплой

Каждый push в `main` или рабочую ветку автоматически публикует игру на GitHub Pages
(`.github/workflows/deploy.yml`).

## Игровая механика

- **XP за реальный результат.** «Сделано полностью» — 100%, «частично» — ровно 50% (XP, GOLD и XP характеристики,
  поэтому бывают половинки: 2,5 XP), «не сделано» — 0 и без штрафа.
  Сложность: 5 / 10 / 25 / 50 / 100 XP, главный квест ×2. Повторно за один квест XP не начисляется.
  Необязательное поле «Что получилось?» сохраняется в History.
- **Уровни:** с L на L+1 нужно `50 + 25·(L−1)` XP (`config/levels.ts`). Названия уровней — там же.
- **Характеристики:** 40% XP квеста идёт в его характеристику, у каждой свой уровень.
- **Босс:** квест снимает HP (−5 / −10 / −15 / −20 / −30, главный — минимум −20, частично — половина с округлением вверх).
  При 0 HP — награда и следующий босс.
- **Серия дней:** день засчитывается при хотя бы одном реальном действии. Каждые 7 дней — щит 🛡,
  который закрывает пропущенный день. Лучшая серия и все активные дни сохраняются навсегда.
- **Цели:** прогресс считается из реальных данных — дохода за месяц, выполненных связанных квестов
  или записанного значения. Milestones с числом закрываются сами (+50 XP).

Данные хранятся в `localStorage` под ключом `lumyl:game` (с версией для миграций).
Перед обновлением формата старые данные копируются в `lumyl:game:backup-v<N>`.

## Задачи: REAL TASKS → INBOX → QUESTS → REWARD → GOALS

Задача из реальной жизни и квест — одна и та же сущность (`Quest`, псевдоним `Task` в `src/types`).
Приложение — надстройка над твоим настоящим списком дел, а не ещё один список.

```
Заметка (Apple Notes) ──импорт──► 📥 Inbox ──«когда?»──► 🔥 Today ──«Выполнить»──► XP · GOLD · характеристика
                                       │                    ▲                          · босс · цель · History
                                       └──► 📋 Backlog ─────┘ (завтра / дата / без даты)
```

**Модель задачи:** `id`, `title`, `source` (`manual` · `notes` · `generated`), `sourceId` (fingerprint),
`context` (заголовок из заметки), `stat` (категория), `difficulty`, XP (вычисляется из сложности),
`status` (`open` · `in_progress` · `done` · `partial` · `skipped` · `archived`), `createdAt`, `dueDate`,
`completedAt`, `goalId`, `description` (заметки), `note` («Что получилось?»), `inbox`, `auto`.

### 📥 Inbox
Всё, что пришло из импорта и ещё не разобрано. Категория, сложность, XP и цель уже определены
автоматически (помечено «авто»). Остаётся выбрать: **Сегодня / Завтра / Позже (дата) / Без даты**.
Задача с датой в тексте заметки минует Inbox и сразу планируется. Задачу можно выполнить и прямо из Inbox.

### 🔥 Today
Только то, что запланировано на сегодня: главный квест сверху, затем «в работе», просроченные,
связанные с целями. Сделанное и «не сделано» свёрнуты в одну строку.
- Невыполненная реальная задача **переносится** на следующий день, пока не будет сделана.
- «Не сделано» — без штрафа; назавтра задача снова становится новой.
- На **Home** — главный квест и максимум 4 задачи из разных направлений, остальное — «ещё N на сегодня».

### 📋 Backlog
Разобранные задачи не на сегодня: «Завтра», «Запланировано» (по датам), «Без даты».
В нужный день задача сама переезжает в Today; кнопка «→ Сегодня» — вручную.

### 🎯 Связь с целями
У каждой задачи есть поле «Какая цель?». Выполнение двигает цель: для целей с прогрессом
«по квестам» — +1 к счётчику, milestones закрываются сами. Цель подставляется автоматически
по категории (учёба → университет, работа → менеджер блогеров, танцы → танцы, деньги → доход);
для бытовых задач (VPN, документы, «написать маме») цель не подставляется. Всё можно поменять.

### Шаблонные квесты
Предложения игры вроде «Учебный блок 40 минут». Главный — только если ты не выбрала главный сама;
обычные — только если реальных задач на сегодня меньше 3 (добор до 4). Как только реальных
задач набирается 3, нетронутые шаблонные скрываются. Полностью выключаются в Character → Настройки.

## Синхронизация Apple Notes → LEVEL UP

**Заметка — источник задач, RPG — система их выполнения.** Ты продолжаешь вести «План задач»
в Apple Notes как обычно, а игра забирает из неё новое.

### Почему нет прямой интеграции с Apple Notes
У Apple Notes **нет публичного API** — ни веб-версии с доступом для сторонних сайтов, ни iCloud API.
LEVEL UP — статичный сайт на GitHub Pages, у него нет и не может быть доступа к твоим заметкам.
Прочитать заметку на iPhone могут только приложения Apple, в том числе **Команды (Shortcuts)**.

### Какой вариант выбран и почему
Исследованы варианты (от более автоматического к более ручному):

| Вариант | Работает с иконкой на экране «Домой»? | Вердикт |
|---|---|---|
| **A. Shortcut → буфер обмена → «⚡ Быстрый импорт»** | ✅ | **Основной.** Надёжно, без backend. |
| **Б. Shortcut → ссылка `#/import?text=…`** | ❌ (откроется в Safari) | Для тех, кто играет во вкладке Safari: предпросмотр открывается сам. |
| **В. «Поделиться» в Notes → Shortcut** | ✅ (через буфер) | Зависит от версии iOS; запасной путь. |
| Web Share Target («Поделиться» → сайт) | ❌ | Safari на iOS не поддерживает. |
| Свой endpoint (полная автоматика) | ✅ | Нужен backend — см. «Нужен ли backend» ниже. |

Ключевое ограничение iOS: **приложение, добавленное на экран «Домой», хранит данные отдельно от Safari.**
Ссылки, которые открывает Shortcut, всегда открываются в Safari — то есть в другой копии игры.
Единственный общий для всей системы канал без сервера — **буфер обмена**. Читать его сайт может
только по нажатию (iOS показывает пузырь «Вставить») — поэтому сценарий занимает 2–3 нажатия, а не 0.
Лучше надёжный импорт в пару нажатий, чем «магия», которая нестабильно работает на iPhone.

**Пошаговая сборка Shortcut — [docs/SHORTCUT.md](docs/SHORTCUT.md)** (та же инструкция кратко —
в игре: Quests → Inbox → ⚙️).

### Сценарий
1. Обновляешь заметку «План задач» в Apple Notes.
2. Запускаешь команду **«В LEVEL UP»** (виджет, Siri, двойное касание задней панели).
   Команда: «Найти заметки» (название = «План задач») → «Получить текст» → «Скопировать в буфер».
3. Открываешь LEVEL UP → **«⚡ Импорт»** на главном экране (или Inbox → «⚡ Быстрый импорт») → «Вставить».
4. Предпросмотр: **Найдено · Новых · Уже есть · Выполнено ✓ · В архив** и список задач с тем,
   что с каждой произойдёт.
5. **«Импортировать всё»** (или «Только новые»). Новые задачи — в Inbox.

### Куда передавать текст
- Буфер обмена → кнопка «⚡ Быстрый импорт» (`ClipboardSource`).
- Или ссылка: `https://vio7letta-lab.github.io/level-up-my-life/#/import?text=<текст, URL-encoded>`
  (`ShortcutUrlSource`). Всё после `#` не отправляется на сервер; после чтения текст стирается
  из адресной строки и истории. Предел ~30 000 символов (~150+ задач); длиннее — через
  `#/import?clipboard` (открывает импорт с кнопкой вставки).
- Или вручную: Inbox → 📋 → вставить текст в поле.

### Правила синхронизации
| В заметке | В игре |
|---|---|
| Новая строка ☐ | новая задача → Inbox (с датой в тексте — сразу в план) |
| Та же заметка импортирована ещё раз (хоть 10 раз) | ничего не меняется |
| Строку удалили | **ничего не удаляется** — задача остаётся в игре |
| Текст строки поправили (опечатка, уточнение, порядок слов) | та же задача, дубль не создаётся; название обновится, если ты не переименовывала задачу в игре |
| Строку перенесли под другой заголовок | та же задача (совпадение текста) |
| Активную задачу отметили ☑ | закрывается **с полной наградой ровно один раз** |
| ☑ у задачи, которую игра видит впервые | архив **без XP** |
| ☑ у уже закрытой / архивной задачи | ничего (награда не повторяется) |

- **«Импортировать всё»** — новые + закрытие ☑ с наградой + архив выполненных.
  **«Только новые»** — только новые задачи, существующие не трогаются. Оба режима не создают дублей.
- **Защита от дублей:** у каждой задачи стабильный fingerprint = нормализованный текст + заголовок
  (регистр, ё/е, пунктуация, маркеры и дата не важны). Прежние fingerprints задачи сохраняются
  (`sourceAliases`), поэтому и старый, и новый текст узнаются.
- **Правка текста** определяется осторожно (`src/game/importer.ts`): сравниваются значимые слова,
  опечатки и окончания прощаются, но «Написать Владе» ≠ «Написать Лере», «Лаба 1» ≠ «Лаба 2»,
  а с выполненной задачей правка не склеивается. В предпросмотре такая задача помечена
  «текст изменён — было: …», и есть кнопка **«это новая задача»**, если склейка не нужна.
- Все награды начисляются только через общий `completeQuest` — импорт не может выдать XP дважды.
- **Журнал импортов** (`importLog`, последние 20): «Последний импорт: сегодня, 15:42 · найдено 17 ·
  новых 13 · уже есть 4» — карточка «Источник задач» в Inbox.

### Если Safari / iOS блокирует вставку
- Нет пузыря «Вставить» — нажми «⚡ Быстрый импорт» ещё раз.
- «Доступ к буферу не разрешён» — открой 📋, долгое нажатие в поле → «Вставить».
- «Буфер обмена пуст» — команда не нашла заметку: проверь точное название в фильтре.
- Чек-лист пришёл без ☐/☑ — проверь текст действием «Быстрый просмотр» (см. docs/SHORTCUT.md);
  без отметок все строки импортируются как открытые.

### Как проверить импорт
`☐ Тест 1`, `☐ Тест 2`, `☑ Тест 3` → импорт: новых 2, в архив 1 → повтор: уже есть 3 →
`☑ Тест 1` → импорт: выполнено ✓ 1 (награда) → повтор: награды нет → удалить «Тест 2» из заметки →
импорт: в игре «Тест 2» остаётся. Подробно — в docs/SHORTCUT.md.

### Нужен ли backend
Для текущего сценария — **нет**: всё работает на GitHub Pages. Backend понадобится только для
**полностью автоматического** импорта (Shortcut отправляет заметку сам, без буфера и нажатий в игре):
- **зачем:** у статичного сайта нет адреса, куда можно отправить данные, а приложение на экране «Домой»
  не может получить их из Safari;
- **где:** например, Cloudflare Workers + KV (бесплатного тарифа хватает) или Supabase;
- **что хранить:** последний текст заметки (или список задач) и время отправки; доступ по личному токену;
- **сложность:** +1 сервис, токен в Shortcut и в игре, обработка ошибок сети; заодно появятся облачная
  копия прогресса и синхронизация телефона с компьютером;
- **можно ли обойтись:** да — текущий вариант через буфер обмена; разница — 2–3 нажатия.

В коде для этого уже есть место: интерфейс `TaskSource` (`src/sources/`) и реестр источников
(`src/sources/registry.ts`). Новый источник (backend, Reminders, Todoist, Google Tasks, Notion, Telegram)
реализует `getTasks()` — дальше задачи идут через тот же движок: классификация → XP → цель →
Inbox/Today → награда → History.

### Что остаётся ограничением
- Полностью «без нажатий» без backend невозможно: iOS разрешает сайту читать буфер только по нажатию.
- Как именно Shortcuts превращает чек-лист Notes в текст (сохраняются ли ☐/☑), зависит от iOS —
  проверяется один раз на телефоне.
- Сильно переписанный текст задачи (другие слова) игра посчитает новой задачей — старая останется,
  её можно убрать вручную.
- Ссылочный вариант (Б) не подходит для иконки на экране «Домой» — только для вкладки Safari.

### Формат заметки

```
План задач:                      ← строка с «:» — заголовок
Книга спроси маму                ← строка без маркера — задача

Учёба                            ← строка над списком — категория/контекст
○ Лаба ВМС спросить у Сажнева    ← ○ □ ☐ ◦ • - [ ] — открытая задача
○ Коллоквиум до 20.10            ← дата распознаётся и убирается из текста
✓ Лаба теор                      ← ✓ ✔ ☑ [x] — выполненная
```

- Пустые строки и «...» игнорируются; текст без маркеров и заголовков — каждая строка задача.
- Даты: `сегодня`, `завтра`, `послезавтра`, `15.10`, `15.10.2026`, `до 20.10`, `15 октября`.
  Дата без года, которая уже давно прошла (например, «15.01» в октябре), считается следующим годом.
- **Без дубликатов:** у каждой задачи стабильный fingerprint = нормализованный текст + заголовок
  (регистр, ё/е, пунктуация, маркеры и дата не важны). Повторный импорт той же заметки ничего не дублирует.
  Убранная из RPG задача уходит в архив и при следующем импорте не вернётся.
- **Выполненные (✓):** при первом импорте — в архив **без XP** (иначе первая же заметка выдала бы
  десятки наград). Если задача уже была активной в RPG, а в заметке стала ✓ — она закрывается
  **с полной наградой ровно один раз** (через тот же `completeQuest` с защитой от двойного начисления).

## Автоматическая оценка

Правила лежат в `src/config/classifier.ts` (без ИИ, легко дополнять), логика — `src/game/classify.ts`.

**Категория** — первое подходящее правило:
1. сильные слова в тексте: лаба / коллоквиум / экзамен → 🧠 Knowledge; резюме / КП / клиент / бренд → 💼 Career;
   пост / reels / контент → 📱 Media; танцы / тренировка → 💃 Energy; билеты / поездка → 🌍 Freedom;
   VPN / документы / банк → 🌍 Freedom (без цели); заработать / ₽ / доход → 💰 Finance;
2. заголовок заметки: «Учёба» → Knowledge, «Работа» → Career, «Блог» → Media, «Спорт» → Energy…;
3. слабые слова: написать / позвонить / созвониться / встретиться → 🤝 Social; разобраться / изучить → Knowledge;
4. иначе — Freedom.

**Сложность → XP:**

| Сложность | XP | Когда |
|---|---|---|
| Маленькая | 5 | начинается с «написать», «спросить», «позвонить», «купить»… |
| Обычная | 10 | по умолчанию; «лаба + спросить» тоже обычная |
| Сложная | 25 | лаба, КП, резюме, отчёт, тренировка, переговоры, «составить» |
| Большая | 50 | экзамен, коллоквиум, защита, сессия; число от 20 в тексте («50–100 резюме») |
| Главный квест | ×2 | до 100 XP — отметка «⚔️ Главный квест дня» |

Если оценка не подошла — тап по задаче, и категория, сложность и цель меняются вручную.

## Будущие интеграции

Слияние задач из любого источника делает чистая функция `importTasks()` (дедупликация по `sourceId`,
архив / закрытие ✓ с наградой). Источник реализует интерфейс `TaskSource` (`src/sources/TaskSource.ts`):

```ts
interface TaskSource {
  getTasks(): Promise<ParsedTask[]>   // прочитать задачи из источника
  import(state, now)                  // слить с игрой
  sync(state, now)                    // повторить — идемпотентно
}
```

Сейчас реализованы `ManualTextSource` (вставленный текст), `ClipboardSource` (буфер обмена) и
`ShortcutUrlSource` (ссылка `#/import?text=`). Что можно подключить дальше:

| Вариант | Возможно? | Как и что нужно |
|---|---|---|
| **Apple Notes напрямую** | ❌ | У Apple Notes нет публичного API (ни веб, ни iCloud). Сайт не может читать заметки. |
| **iOS Shortcuts → буфер** | ✅ реализовано | Основной способ — см. «Синхронизация Apple Notes → LEVEL UP» и [docs/SHORTCUT.md](docs/SHORTCUT.md). |
| **Shortcuts → ссылка `#/import?text=`** | ✅ реализовано | Для игры во вкладке Safari; иконка на экране «Домой» хранит данные отдельно от Safari. |
| **Web Share Target** («Поделиться» → RPG) | ❌ на iOS | Поддерживается только Chrome/Android. |
| **Свой API endpoint** | нужен backend | GitHub Pages — статичный хостинг, принимать запросы не умеет. Небольшой backend (Cloudflare Workers + KV или Supabase): Shortcut отправляет текст заметки POST-запросом, RPG забирает при открытии. Заодно — облачная копия и синхронизация устройств. |
| **Apple Reminders через Shortcuts** | ✅ | Shortcuts отдаёт напоминания структурно (срок, выполнено, список) — надёжнее разбора текста. Тот же путь через буфер или backend. |
| **Todoist** | ✅ | Официальный REST API, личный токен, даты и статус. Перед реализацией проверить, разрешены ли запросы из браузера (CORS); если нет — через backend. |
| **Google Tasks** | ✅ | OAuth прямо в браузере (Google Identity Services) работает на статичном сайте; нужен проект в Google Cloud. |
| **Notion** | ⚠️ | API не разрешает запросы из браузера — нужен backend-прокси. |

**Рекомендация:** сейчас — Apple Notes + команда Shortcuts «Скопировать задачи» + «Вставить из буфера»:
привычка писать в Notes сохраняется, backend не нужен. Следующий шаг автоматизации — маленький backend
на Cloudflare Workers: он закрывает сразу три вещи (приём задач из Shortcuts без ручных действий,
облачная копия, синхронизация телефона и компьютера). Внешний таск-менеджер (Todoist) имеет смысл,
только если захочется уйти из Notes.

### Ограничения Apple Notes — честно
- Нет API: ни приложение, ни сайт не могут сами прочитать заметку. Только ты (копированием)
  или Shortcuts на твоём iPhone.
- Как выглядит чек-лист после копирования (какие символы стоят у пунктов), зависит от способа копирования
  и версии iOS — это стоит проверить на своём телефоне. Парсер понимает ○ □ ☐ ◦ • - [ ] и ✓ ✔ ☑ [x];
  если отметок в тексте нет, все строки импортируются как открытые задачи.
- Сайт на GitHub Pages не может работать в фоне и сам «забирать» задачи по расписанию.
