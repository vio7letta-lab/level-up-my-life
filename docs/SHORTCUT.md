# Shortcut «В LEVEL UP»: Apple Notes → LEVEL UP

Пошаговая инструкция для iPhone. Один раз собрать команду — дальше обновление задач занимает 1 запуск
команды и 2–3 нажатия в игре.

> Названия действий приведены на русском (как в русской iOS) и в скобках — на английском.
> В разных версиях iOS формулировки могут немного отличаться: ищи действие поиском по ключевому слову
> («заметки», «текст», «буфер»).

## Зачем Shortcut и почему через буфер обмена

- **У Apple Notes нет публичного API.** Ни сайт, ни любое веб-приложение не могут сами прочитать заметку.
  Читать заметки умеют только приложения Apple на самом iPhone — в том числе **Команды (Shortcuts)**.
- **Приложение на экране «Домой» хранит данные отдельно от Safari.** Любая ссылка, которую открывает
  Shortcut, открывается в Safari — то есть в другом хранилище, не там, где твой прогресс.
- **Буфер обмена общий для всей системы.** Поэтому основной способ: Shortcut копирует текст заметки,
  а LEVEL UP забирает его кнопкой «⚡ Быстрый импорт».

Если ты пользуешься игрой во вкладке Safari (а не иконкой на экране «Домой»), есть вариант Б —
Shortcut сразу открывает предпросмотр импорта по ссылке, без буфера.

---

## Вариант А (основной): иконка на экране «Домой» + буфер обмена

### Собрать команду

1. Открой приложение **Команды** → вкладка «Команды» → **«+»** (новая команда).
2. Нажми на название сверху → **«Переименовать»** → `В LEVEL UP`.
   (Там же можно выбрать иконку и цвет — например, фиолетовый ⚡.)
3. **Действие 1 — «Найти заметки»** (*Find Notes*).
   - Нажми «Добавить действие», найди поиском «Найти заметки».
   - Нажми **«Добавить фильтр»** → выбери **«Название»** (*Name*) → условие **«является»** (*is*) →
     впиши точное название заметки: `План задач`.
   - Включи **«Ограничить»** (*Limit*) → **1**.
4. **Действие 2 — «Получить текст из входных данных»** (*Get Text from Input*).
   - Входные данные — **«Заметки»** (результат действия 1). Обычно подставляется само.
   - Это действие превращает заметку в обычный текст.
5. **Действие 3 — «Скопировать в буфер обмена»** (*Copy to Clipboard*).
   - Входные данные — **«Текст»** (результат действия 2).
6. **Действие 4 — «Показать уведомление»** (*Show Notification*).
   - Текст: `Задачи скопированы — открой LEVEL UP → ⚡ Быстрый импорт`.
7. Нажми **«Готово»**.

Итог — 4 действия:

```
Найти заметки   [Название является «План задач»] [Ограничить: 1]
      ↓
Получить текст из входных данных   [Заметки]
      ↓
Скопировать в буфер обмена   [Текст]
      ↓
Показать уведомление   «Задачи скопированы — открой LEVEL UP → ⚡ Быстрый импорт»
```

### Первый запуск: проверь, какой текст получается

Важно один раз проверить, как Shortcuts превращает чек-лист Notes в текст:

1. Временно добавь после действия 2 действие **«Быстрый просмотр»** (*Quick Look*) и запусти команду.
2. Посмотри на текст:
   - видны **☐ / ☑** (или ○ / ✓, ◦, •, `[ ]`, `[x]`) у пунктов — отлично, выполненные будут закрываться;
   - отметок **нет** — все строки импортируются как открытые задачи. Тогда выполненное помечай в заметке
     символом в начале строки (`✓ Лаба теор`) или просто вычёркивай/удаляй строку и закрывай задачу в игре.
3. Удали «Быстрый просмотр» из команды.

Пришли разработчику кусок этого текста, если формат странный — парсер легко подстроить.

### Как запускать быстро

Любой из способов:
- **Виджет «Команды»** на экране «Домой»;
- кнопка «Поделиться» → **«На экран „Домой“»** в настройках команды — отдельная иконка;
- **Siri**: «Привет, Siri, в LEVEL UP»;
- **Касание задней панели**: Настройки → Универсальный доступ → Касание → Касание задней панели →
  Двойное касание → «В LEVEL UP».

### Каждодневный сценарий

1. Обновляешь заметку «План задач» в Apple Notes как обычно.
2. Запускаешь **«В LEVEL UP»** (виджет / Siri / двойное касание).
3. Открываешь **LEVEL UP** (иконка на экране «Домой»).
4. На главном экране — **«⚡ Импорт»** (или Quests → Inbox → «⚡ Быстрый импорт»).
5. iOS покажет пузырь **«Вставить»** — нажми его (это защита iOS: сайт не может читать буфер без твоего согласия).
6. Предпросмотр: **Найдено · Новых · Уже есть · Выполнено ✓ · В архив** → **«Импортировать всё»**.
7. Новые задачи — в Inbox. Разбери: Сегодня / Завтра / Позже / Без даты.

## Вариант Б: игра во вкладке Safari — импорт по ссылке

Подходит, если LEVEL UP открыт в Safari (закладка), а не иконкой на экране «Домой».
Предпросмотр открывается сам, остаётся одно нажатие «Импортировать».

1–4. Действия 1–2 как в варианте А (**Найти заметки** → **Получить текст из входных данных**).
5. **«Кодировать URL»** (*URL Encode*) — режим **«Кодировать»**, вход — «Текст».
6. **«Текст»** (*Text*) — впиши адрес и сразу после `text=` вставь переменную **«Закодированный URL»**
   (результат действия 5):

   ```
   https://vio7letta-lab.github.io/level-up-my-life/#/import?text=[Закодированный URL]
   ```
7. **«Открыть URL-адреса»** (*Open URLs*) — вход: «Текст» из действия 6.

Формат ссылки:

```
<адрес игры>#/import?text=<текст заметки, закодированный как URL>
```

- Всё после `#` **не отправляется на сервер** — текст заметки не попадает в логи GitHub Pages.
- После чтения игра сразу убирает текст из адресной строки и истории браузера.
- Если заметка очень большая (больше ~150 задач), ссылка может стать слишком длинной. Тогда вместо
  действий 5–7: **«Скопировать в буфер обмена»** → **«Открыть URL-адреса»** с адресом
  `https://vio7letta-lab.github.io/level-up-my-life/#/import?clipboard` — откроется окно импорта
  с кнопкой «⚡ Вставить из буфера».

> ⚠️ Не используй вариант Б, если играешь через иконку на экране «Домой»: ссылка откроется в Safari,
> и задачи попадут в отдельную копию игры в Safari, а не в твою.

## Вариант В: «Поделиться» из Apple Notes

Можно вызывать ту же команду из заметки:
1. В настройках команды (кнопка ⓘ внизу) включи **«Показывать в меню „Поделиться“»** (*Show in Share Sheet*),
   типы входных данных — **«Текст»** и **«Форматированный текст»** (*Rich Text*).
2. Замени действие «Найти заметки» на **«Получить» → «Входные данные команды»** (*Shortcut Input*).
3. В заметке: **«Поделиться»** → «В LEVEL UP».

Работает ли передача заметки в меню «Поделиться», зависит от версии iOS — если пункта нет или текст
приходит пустым, используй вариант А (он не зависит от меню «Поделиться»).

## Если Safari / iOS блокирует вставку

- **Нет пузыря «Вставить»** → нажми «⚡ Быстрый импорт» ещё раз; пузырь появляется рядом с кнопкой.
- **«Доступ к буферу не разрешён»** → открой окно импорта (📋 рядом с «⚡ Быстрый импорт»), долгое нажатие
  в поле текста → «Вставить» → предпросмотр появится сам.
- **«Буфер обмена пуст»** → команда не нашла заметку: проверь точное название в фильтре
  (регистр, пробелы, «ё»). Добавь «Быстрый просмотр» после действия 1, чтобы увидеть, что найдено.

## Как проверить, что импорт работает

1. В заметке «План задач» три строки: `☐ Тест 1`, `☐ Тест 2`, `☑ Тест 3`.
2. Запусти «В LEVEL UP» → LEVEL UP → «⚡ Импорт» → «Вставить».
   Ожидание: **Найдено 3 · Новых 2 · В архив 1**.
3. Ещё раз то же самое. Ожидание: **Уже есть 3**, кнопка «Всё уже в игре».
4. В заметке отметь `☑ Тест 1` → импорт. Ожидание: **Выполнено ✓ 1** → после импорта награда за Тест 1.
5. Ещё раз импорт — награда **не** повторяется.
6. Удали строку «Тест 2» из заметки → импорт: в игре «Тест 2» остаётся.
7. Убери тестовые задачи из игры (✎ → «Убрать задачу»).
